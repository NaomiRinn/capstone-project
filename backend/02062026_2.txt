  terdekat, mis. Southeast Asia / Singapore).
  4. Klik Create new project → tunggu ±2 menit sampai project aktif.

  Langkah 2 — Ambil URL & Key
  1. Di project, buka Project Settings (ikon gerigi) → API.
  2. Catat dua nilai ini:
    - Project URL → untuk SUPABASE_URL (contoh: https://abcdxyz.supabase.co)
    - Project API keys → service_role → untuk SUPABASE_KEY

  ▎ insert/update/delete langsung ke tabel (scans.py:135, 83, 224). service_role
  ▎ key mem-bypass Row Level Security, jadi cocok untuk backend tepercaya.
